# KeepTool Hora - Schema browser for Oracle you administer

The schema tree and the worksheet should stay on objects you administer. Extra schemas wait for their own title.

## Session Card

| Slice | What you do in KeepTool Hora | What remains |
|-------|------------------------------|--------------|
| Arrival | Open KeepTool Hora on an instance you administer and name the Oracle desk | A titled object session |
| Focus | Keep the schema browser on one tree you administer | A short object list |
| Check | Read the tree before you change objects you own | A confirmed SQL worksheet |
| Handoff | Leave KeepTool Hora SQL worksheet on that instance | A note for the next visit |

## How KeepTool Hora Sits

KeepTool Hora does not replace the Oracle instance you already administer. It sits beside that engine as a named schema browser and SQL worksheet for a KeepTool Hora Oracle desk you own.

The object session stays small on purpose. Extra schemas wait for their own title instead of crowding the live tree.

## Traffic Light

| Signal | On the KeepTool Hora Oracle desk | What you do |
|--------|----------------------------------|-------------|
| Green | Named instance, tree beside the worksheet | Continue the same object session |
| Amber | Two schemas mixed in one tree | Split the set before a large change |
| Red | No title, objects from everywhere | Stop and name the Oracle desk first |
| Clear | Handoff written, object list short | Close KeepTool Hora and leave the desk |

## Open Order

1. Open the last KeepTool Hora session on an instance you administer, not a new empty browser.
2. Read the schema browser and the last SQL worksheet.
3. Finish one visible change inside KeepTool Hora schema browser.
4. Write what changed on objects you own, then close with fewer loose trees than you found.
5. If the Oracle desk feels crowded, drop anything that belongs to a different schema.

## After a Week

A week in KeepTool Hora is not a bigger schema tree. It is the same browser, a shorter worksheet, and a note that still makes sense on Monday. Leave the Oracle desk quieter than the session you opened.

## Sign-off

- [ ] The KeepTool Hora workspace name is short enough to scan
- [ ] Only objects you administer are in the tree
- [ ] A second person can read the last worksheet
- [ ] The last KeepTool Hora session still opens after a restart
- [ ] Finished objects are off the live set
- [ ] The schema browser still matches KeepTool Hora SQL worksheet

## Field Note

KeepTool Hora is easier to trust when the schema browser stays smaller than the export folder around it. Name the Oracle desk, keep the tree on objects you administer, finish one visible step, and write what changed. Open the last KeepTool Hora object session and continue.
